## `> featured_projects`

### [Astra](https://github.com/Kawasanchezz/Astra) · [demo](https://astra-nine-omega.vercel.app)

Chatbot educacional com IA que ajuda estudantes a aprender programação, tirar dúvidas de código e encontrar bugs de forma didática. Back-end com API REST própria em Flask, integrada a um modelo de linguagem (LLM), com rate limiting, CORS restrito, camada de segurança antes do modelo e mascaramento de segredos. A chave de API fica em variáveis de ambiente e há modo de demonstração sem chave. Pipeline no GitHub Actions com CodeQL e Dependabot. Publicado na Vercel.

### [Cadastro de alunos com Árvore Binária de Busca](https://github.com/Kawasanchezz/ProjetosEstruturadeDados-V1)

Sistema web de cadastro de alunos para 7 campi, com uma Árvore Binária de Busca por campus implementada do zero em Java, sem `TreeMap` nem `Collections.sort`. Inclui cadastro, busca, listagem em ordem alfabética, visualização gráfica da árvore e exclusão (folha, um filho e dois filhos), com API REST, servidor HTTP embutido, interface web responsiva e testes automatizados. Sem dependências externas.
